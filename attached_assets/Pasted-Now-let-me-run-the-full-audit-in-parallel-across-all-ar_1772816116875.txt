  Top 3 Blockers Before Filing a Real Permit

  ❌ 1. Playwright Browser Binaries Not Installed

  Impact: Form discovery AND portal automation both fail immediately with "executable not found."
  Fix: Run npx playwright install chromium once in the Replit shell. This downloads the actual Chromium
  browser. Without it, both web crawling and ViewPoint portal automation are dead.

  ⚠️  2. SESSION_SECRET Must Be a Stable, Set Value

  Impact: Portal credentials are encrypted using SESSION_SECRET as the key. If it auto-generates on each
  restart (current behavior when unset), every stored portal credential becomes unreadable after a server
  reboot — causing portal automation to fail with a decrypt error.
  Fix: Set SESSION_SECRET to a fixed random string in Replit Secrets (e.g. openssl rand -hex 32).

  ⚠️  3. PDF Auto-Fill Untested End-to-End Post-Refactors

  Impact: fillPdfFromDatabase() had significant changes in the last two sessions (cross-section dedup,
  field priority reordering). These have not been validated with a real West Hartford form + real profile
  data.
  Fix: Do one live test: pick a West Hartford form, link it to a permit, hit "Generate Filled Form",
  download the PDF, and verify the fields are correct and no bleed-over occurs.
